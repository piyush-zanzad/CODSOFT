# Cool Calculator Website

## Overview

The Cool Calculator is a beginner-friendly web development project created using HTML, CSS, and JavaScript. This project performs basic arithmetic operations such as addition, subtraction, multiplication, division, and percentage calculations.

The calculator features a modern glassmorphism user interface with responsive design and interactive button effects. It is designed to help beginners understand the fundamentals of front-end web development and JavaScript functionality.

---

# Features

* Responsive calculator layout
* Stylish glassmorphism design
* Addition, subtraction, multiplication, and division operations
* Percentage calculation support
* Clear display button
* Delete last character functionality
* Hover animations and button effects
* Error handling for invalid expressions

# How to Run the Project

1. Download or clone the project folder.
2. Open the folder in VS Code.
3. Make sure all files are in the same directory.
4. Open `index.html` in any web browser.

---

# Working of the Calculator

1. User clicks buttons to enter numbers and operators.
2. JavaScript updates the display dynamically.
3. Clicking the `=` button evaluates the expression.
4. The result is displayed on the screen.
5. The `C` button clears the display.
6. The `DEL` button removes the last entered character.
