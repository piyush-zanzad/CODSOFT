# Personal Portfolio Website

## Overview

This project is a simple and responsive Personal Portfolio Website created using HTML and CSS. It is designed for beginners who want to practice front-end web development and create their own professional portfolio website.

The portfolio contains multiple sections such as About, Skills, Projects, Resume, Contact, and Footer. It helps showcase personal information, technical skills, and projects in a clean and attractive layout.

---

# Features

* Responsive and user-friendly design
* Header section with name and tagline
* About section with profile image and bio
* Skills section to display technical skills
* Projects section with project descriptions and images
* Resume download button
* Contact information section
* Footer with copyright details

---

# Technologies Used

* HTML5
* CSS3

# Sections Included

## 1. Header Section

Displays the portfolio owner's name and a short introduction or tagline.

## 2. About Section

Contains profile image and a short bio describing experience, interests, and goals.

## 3. Skills Section

Shows technical skills such as HTML, CSS, JavaScript, React, C++, and GitHub.

## 4. Projects Section

Displays sample projects with:

* Project title
* Description
* Project image

## 5. Resume Section

Provides a button to download the resume in PDF format.

## 6. Contact Section

Contains contact details such as:

* Email address
* Phone number

## 7. Footer

Displays copyright information and additional details.

---

# How to Run the Project

1. Download or clone the project folder.
2. Open the project in VS Code.
3. Make sure all images and the resume PDF are placed correctly.
4. Open `index.html` in any web browser.
