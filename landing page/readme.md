# DriveX Car Landing Page

## Overview

DriveX Car Landing Page is a beginner-friendly web development project created using HTML and CSS. This project is designed to showcase a modern and visually appealing landing page for a luxury car website.

The landing page includes a navigation bar, hero section, features section, featured cars showcase, contact section, and footer. The project helps beginners understand webpage layouts, responsive design, CSS styling, and section organization.

---

# Features

* Modern and attractive landing page design
* Responsive layout
* Navigation bar with menu links
* Hero section with call-to-action button
* Features section with service highlights
* Featured car showcase cards
* Contact section with button
* Footer section
* Hover effects and smooth styling

---

* CSS3

1. Download or clone the project folder.
2. Open the folder in VS Code.
3. Make sure all image files are placed correctly.
4. Open `index.html` in any web browser.
