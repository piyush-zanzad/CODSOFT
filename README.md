# CodSoft Web Development Projects

This repository contains beginner-friendly web development projects created using HTML, CSS, and JavaScript as part of the CodSoft Internship tasks.

The projects focus on improving front-end development skills, responsive design, user interface creation, and JavaScript functionality.

# Projects Included

## 1. Personal Portfolio Website

A responsive personal portfolio website designed to showcase:

* Personal information
* Skills
* Projects
* Resume
* Contact details

### Features

* About section
* Skills section
* Project showcase
* Resume download button
* Contact information
* Responsive design

### Technologies Used

* HTML5
* CSS3
